# Figures — Transforming

## Что реализовано

- `Rect`, `Circle`, `Square` наследуются от абстрактного класса `Figure`;
- все три фигуры реализуют интерфейсы `Movable` и `Transforming`;
- реализованы перемещение `move(dx, dy)`;
- реализовано масштабирование `resize(zoom)` с сохранением центра фигуры;
- реализован поворот на 90° по и против часовой стрелки вокруг заданной точки;
- для прямоугольника при повороте на 90° ширина и высота меняются местами;
- для круга и квадрата поворот изменяет положение центра, а форма остается той же.

## Формула поворота

Для точки `(x, y)` относительно центра `(cx, cy)`:

**По часовой стрелке:**

`x' = cx + (y - cy)`  
`y' = cy - (x - cx)`

**Против часовой стрелки:**

`x' = cx - (y - cy)`  
`y' = cy + (x - cx)`

## Демонстрация

Методы проверяются в `Main.kt` в следующем порядке:

1. вывод исходных параметров фигур;
2. перемещение всех фигур;
3. масштабирование в 2 раза;
4. поворот по часовой стрелке на 90°;
5. поворот против часовой стрелки на 90°.

### Пример вывода

```text
=== Начальные фигуры ===
Rect(x=2, y=2, width=4, height=2)
Circle(x=4, y=3, radius=2)
Square(x=2, y=2, side=4)

=== Перемещение ===
Rect(x=3, y=1, width=4, height=2)
Circle(x=6, y=4, radius=2)
Square(x=1, y=4, side=4)

=== Масштабирование x2 ===
Rect(x=1, y=0, width=8, height=4)
Circle(x=6, y=4, radius=4)
Square(x=-1, y=2, side=8)

=== Поворот по часовой стрелке на 90° вокруг (4, 3) ===
...
```
